# Key Structs Reference

This document serves as a lookup table for every key struct in the system.

## 1. Events & Communication

### `Myelin.Event`
**Description:** Represents an inbound event from an interface to the system.
**Flow:** Created by Interfaces, enriched by `EventEnricher`, consumed by `InferenceRouter`.
| Field | Type |
|-------|------|
| `id` | `String.t()` |
| `source` | `atom()` |
| `kind` | `atom()` |
| `payload` | `map()` |
| `sender` | `String.t() \| nil` |
| `thread_id` | `String.t() \| nil` |
| `platform` | `atom()` |
| `raw` | `map()` |
| `inserted_at` | `DateTime.t()` |
| `signals` | `map()` |

### `Myelin.OutputEvent`
**Description:** A formal schema for "the system wants to do something on a platform" (outbound event).
**Flow:** Emitted by `StateMachine` / `Engaged`, routed by `OutputPipeline`, delivered by Interfaces.
| Field | Type |
|-------|------|
| `id` | `String.t()` |
| `action` | `atom()` |
| `target_interface` | `module()` |
| `target` | `map()` |
| `content` | `map()` |
| `source_event_id` | `String.t() \| nil` |
| `decided_by` | `atom()` |
| `confidence` | `float() \| nil` |
| `priority` | `:low \| :normal \| :urgent` |
| `requires_approval` | `boolean()` |
| `status` | `:pending \| :pending_approval \| :approved \| :delivering \| :delivered \| :failed` |
| `conversation_id` | `String.t() \| nil` |
| `created_at` | `DateTime.t()` |
| `delivered_at` | `DateTime.t() \| nil` |
| `delivery_receipt` | `map() \| nil` |
| `retry_count` | `integer()` |
| `max_retries` | `integer()` |

## 2. Conversations

### `Myelin.Conversation`

**Flow:** Managed by `ConversationRegistry` and `MemoryStore.Conversations`, updated during enrichment and routing.
| Field | Type |
|-------|------|
| `id` | `String.t() \| nil` |
| `source` | `atom() \| nil` |
| `root_event_id` | `String.t() \| nil` |
| `participants` | `list(map())` |
| `turn_count` | `integer()` |
| `our_turn_count` | `integer()` |
| `depth` | `integer()` |
| `branch_count` | `integer()` |
| `topic_signature` | `list(float()) \| nil` |
| `topic_keywords` | `list(String.t())` |
| `conversation_type` | `atom() \| nil` |
| `sentiment` | `atom() \| nil` |
| `cumulative_salience` | `float()` |
| `peak_salience` | `float()` |
| `salience_trend` | `atom()` |
| `last_salience` | `float()` |
| `tracking_level` | `atom()` |
| `policy_overrides` | `map()` |
| `last_agent_action` | `any()` |
| `agent_role` | `atom() \| nil` |
| `state` | `atom()` |
| `opened_at` | `DateTime.t() \| nil` |
| `last_activity` | `DateTime.t() \| nil` |
| `idle_since` | `DateTime.t() \| nil` |
| `closed_at` | `DateTime.t() \| nil` |
| `summary` | `String.t() \| nil` |
| `summary_updated_at` | `DateTime.t() \| nil` |
| `summary_covers_turn` | `integer()` |

### `Myelin.ConversationContext`
**Description:** Lightweight conversation data for the enrichment/routing hot path.
**Flow:** Extracted from full `Conversation`, stored in ETS, injected into `Event.signals` by `EventEnricher`.
| Field | Type |
|-------|------|
| `id` | `String.t() \| nil` |
| `tracking_level` | `atom() \| nil` |
| `cumulative_salience` | `float() \| nil` |
| `salience_trend` | `atom() \| nil` |
| `conversation_type` | `atom() \| nil` |
| `turn_count` | `integer() \| nil` |
| `our_turn_count` | `integer() \| nil` |
| `last_activity` | `DateTime.t() \| nil` |
| `policy_overrides` | `map()` |
| `topic_keywords` | `list(String.t())` |

## 3. Interfaces & State

### `Myelin.Interface.Capabilities`
**Description:** A structured description of what an interface can do.
**Flow:** Defined by Interfaces, consumed by `InferenceRouter` and `OutputPipeline` to determine available actions.
| Field | Type |
|-------|------|
| `interface` | `module()` |
| `direction` | `:input \| :output \| :bidirectional` |
| `platform_name` | `String.t()` |
| `platform_identity` | `String.t() \| nil` |
| `audience` | `String.t()` |
| `actions` | `[map()]` |
| `input_kinds` | `[atom()]` |

### `Myelin.StateMachine.Policy`
**Description:** Threshold policy regulating event escalation and inference concurrency per state.
**Flow:** Loaded by `StateMachine` based on current agent state, dictates routing thresholds and cooldowns.
| Field | Type |
|-------|------|
| `event_floor` | `float()` |
| `escalation_threshold` | `float()` |
| `cooldown_seconds` | `integer()` |
| `max_concurrent_inferences`| `integer()` |

## 4. System & Infrastructure

### `Myelin.Budget.CostSummary`
**Description:** Generates a cost context block for monitoring budget across tiers (Haiku, Sonnet, Opus).
**Flow:** Generated by `Budget` GenServer from tracked API usage, used for context windows and alerts.
| Field | Type |
|-------|------|
| `total_24h` | `float()` |
| `breakdown_by_tier` | `%{atom() => float()}` |
| `top_cost_drivers` | `[%{session_id: String.t(), cost: float()}]` |
| `remaining_budget` | `float()` |
| `in_conservation_mode` | `boolean()` |

### `Myelin.Cache.Layer`
**Description:** Represents a cache layer content and its lifecycle metrics.
**Flow:** Created and managed by `Myelin.Cache.Manager`, used across prompt assembly to reduce token costs.
| Field | Type |
|-------|------|
| `id` | `String.t()` |
| `level` | `0 \| 1 \| 2` |
| `ttl_strategy` | `:one_hour \| :five_min` |
| `content` | `String.t()` |
| `content_hash` | `String.t()` |
| `token_count` | `non_neg_integer()` |
| `created_at` | `DateTime.t()` |
| `last_hit_at` | `DateTime.t()` |
| `expires_at` | `DateTime.t()` |
| `hit_count` | `non_neg_integer()` |
| `source_hashes` | `map()` |
| `divergence_score` | `float()` |

### `Processor Task` (Map)
**Description:** Task map representing an async operation handled by the `Processor`.
**Flow:** Enqueued into `Myelin.Processor`, executed asynchronously via `Myelin.TaskSupervisor` leveraging `LlamaClient`.
| Field | Type |
|-------|------|
| `operation` | `atom()` |
| `args` | `map()` |
| `request_id` | `String.t()` |
| `reply_to` | `pid()` |
| `priority` | `:real \| :speculative` |
| `context_id` | `String.t() \| nil` |
| `inserted_at` | `DateTime.t()` |
| `task` | `Task.t() \| nil` |
